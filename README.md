Amazon Website Clone 🛒

A frontend e-commerce website inspired by Amazon, built using HTML, CSS, and JavaScript.

This project demonstrates a basic shopping experience with products, cart management, product details, checkout, and order confirmation.

🚀 Features
🏠 Amazon-style home page
🛍️ Product listing
🔍 Product search
⭐ Product ratings and reviews
📦 Product details page
🛒 Add products to cart
➕ Increase product quantity
➖ Decrease product quantity
❌ Remove products from cart
💰 Automatic cart total calculation
💳 Checkout page
💵 Multiple payment options
📋 Order confirmation
🧾 Order ID generation
💾 Cart data stored using Local Storage
📱 Responsive website design

▶️ How to Run
Clone the repository:
git clone https://github.com/KunjalVanra/amazon_website_clone.git


Open the project folder in VS Code.

Open index.html in your browser.

You can also use the Live Server extension in VS Code for a better development experience.

🛒 How It Works

Products are displayed on the home page. Users can:

Browse products.
Search for products.
Open a product to view its details.
Add products to the cart.
Change product quantities.
Remove products from the cart.
Proceed to checkout.
Select a payment method.
Place an order.
View the generated order confirmation.

Cart information is stored in the browser's Local Storage, so the cart remains available after refreshing the page.

This project was created for learning and practicing frontend web development, JavaScript DOM manipulation, Local Storage, shopping cart functionality, and GitHub project management.
